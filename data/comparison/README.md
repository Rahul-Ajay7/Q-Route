# Comparison inputs

`solomon/` contains JSON conversions of the supplied C101, R101, and RC101
instances, each with free-flow and synthetic congestion variants. Provenance
and conversion assumptions are recorded inside each JSON file.

The original Solomon text files remain in
[`members/Parikshit/data/solomon`](../../members/Parikshit/data/solomon).
The supplied TC cases remain in
[`members/Rahul/test_cases`](../../members/Rahul/test_cases) alongside their
original indexes and traffic CSVs.

See [the benchmark protocol](../../team_benchmark/README.md) for reproduction.
